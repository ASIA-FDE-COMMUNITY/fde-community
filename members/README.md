# ASIA FDE 会员网络

这个目录帮助企业与从业者找到具备公开、可验证 FDE 能力的个人和团队。

## 会员类型

- FDE 从业者：实际参与 FDE 或生产级 AI 交付的个人；
- 交付团队：能够完成需求梳理、实施、部署和持续支持的公司或团队；
- 行业专家：能够支持业务发现、流程设计、验证或采用的领域专家；
- 技术伙伴：具备真实交付支持经验的基础设施或工具提供方。

## 如何加入

1. 复制 [会员资料模板](PROFILE_TEMPLATE.md)。
2. 保存为 profiles/GitHub用户名.md。
3. 在上面的会员目录中增加一行。
4. 提交 Pull Request。

会员资料应尽量提供公开项目、文章、演讲、工具或其他可验证信息。请勿提交客户机密、私人联系方式、未经授权的项目名称或无法验证的宣传内容。
